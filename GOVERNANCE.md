# Governance

budiff is published under the **WellScoped** identity: the repository lives at [`github.com/wellscoped/budiff`](https://github.com/wellscoped/budiff), and the NuGet packages are owned by the WellScoped NuGet.org organization.

## Maintainers

The lead maintainer is Victor Zakharov ([`@VictorZakharov`](https://github.com/VictorZakharov)), who has final responsibility for releases, security response, repository administration, and decisions that cannot reach consensus.

## Decisions

Small fixes go straight to a pull request. Changes to the scope in [`SPEC.md`](SPEC.md), the layering rules, public library APIs, the CLI's `--json` output, or the MCP tools should be discussed in an issue first.

budiff stays small and read-only: a maintainer may decline work that is correct but outside that scope. Declining a change does not stop anyone from using the MIT-licensed code in a fork.

## Releases

The lead maintainer approves version numbers and releases. The steps are in [`docs/RELEASING.md`](docs/RELEASING.md).

## Succession

Maintainers may be added for sustained, trustworthy contributions. If the lead maintainer steps away, they transfer repository and NuGet ownership to an active maintainer and record it here.
